§ Language

The model writes familiar code.
The checker keeps its promises.

Ward's surface layer (what the model writes) is Python/TypeScript-shaped — the syntax best represented in training corpora. A deterministic elaborator compiles it to a strict core, and Dafny + Z3 prove the contracts. The model never hand-writes dependent types, ownership annotations, or proof scripts.

sum_between.ward0 
fn sum_between(xs: List<int>, lo: int, hi: int) -> int
  requires 0 <= lo and lo <= hi and hi <= len(xs)
  requires forall i in range(0, len(xs)) :: xs[i] >= 0
  ensures result >= 0
{
    var acc: int = 0;
    for i in range(lo, hi)
      invariant acc >= 0
    {
        acc += xs[i];
    }
    return acc;
}
📝

Contracts, not comments

requires / ensures become real type-level predicates the checker must prove — familiar to anyone who's seen design-by-contract.

🔀

Deterministic elaboration

Surface → strict core is a conventional compiler pass, not AI. Auditable, reproducible, and hard-error on anything ambiguous.

🔁

Checker-guided repair loop

Structured (location, obligation, counterexample) errors are translated back into surface terms — the model repairs in the language it's fluent in.

🛡️

Trusted FFI boundary

extern fn + mandatory trust: annotations. The toolchain generates a runtime contract-check wrapper around every unverified-library call.

§ Tiered verification

Full proof where it matters.
Honest testing everywhere else.

Full-stack apps are mostly not algorithmically interesting. Ward pays the expensive proof cost only where the resource-type system says it's mandatory — and lets the rest fall back gracefully.

Tier 1

Tested

Property-based tests generated from the type signature. No proof.

  • UI glue, formatting
  • Simple CRUD handlers
  • Verify: ~0.0 s (smoke ex.)
Tier 2

Contracted

requires / ensures checked; proof search is bounded, with a test-based fallback instead of a hard failure.

  • Business logic
  • Validation, most backends
  • Verify: ~1.3 s (smoke ex.)
Tier 3

Proven

Full SMT/proof-search verification. No timeout fallback. Required for anything touching linear-typed resources.

  • Auth, payments
  • Data-integrity paths
  • Verify: ~1.4 s (smoke ex.)
